## 🔐 Topics Covered

The report focuses on five major cybersecurity threats:

1. **AI-Powered Phishing Attacks**
   - AI-generated phishing and spear-phishing
   - Voice cloning and deepfake video
   - Business Email Compromise
   - Case study: Arup deepfake fraud incident
   - Defensive measures such as out-of-band verification and multi-layered approval

2. **Ransomware-as-a-Service (RaaS)**
   - Ransomware affiliate business model
   - Double-extortion attacks
   - Case study: LockBit and Operation Cronos
   - Offline backups, EDR, network segmentation, and patch management

3. **Cloud Security Misconfigurations**
   - Publicly exposed storage
   - Excessive IAM permissions
   - Missing encryption
   - Case study: Football Australia data breach
   - CSPM, least privilege, encryption, and configuration audits

4. **IoT Vulnerabilities**
   - Weak/default credentials
   - Outdated firmware
   - IoT botnets and DDoS
   - Case studies involving Edimax cameras and TBK DVR devices
   - Firmware updates, credential changes, and network segmentation

5. **Zero-Day Exploits**
   - Vulnerabilities exploited before a patch is available
   - Case study: Ivanti Connect Secure VPN vulnerabilities
   - Rapid patching, IDS/IPS, network monitoring, and Zero Trust

## 🎯 Objectives

- Understand the modern cybersecurity threat landscape.
- Analyze the potential impact of major cyber threats on individuals and organizations.
- Study documented real-world cybersecurity incidents.
- Identify practical defensive and preventive measures.
- Understand how emerging technologies such as generative AI are changing both attacks and defense.

## 🛡️ Key Defensive Themes

The report emphasizes:

- Continuous security monitoring
- Rapid patch management
- Multi-factor and layered verification
- Least-privilege access
- Network segmentation
- Offline and tested backups
- Cloud security posture management
- Security awareness training
- Zero Trust architecture
- Continuous cybersecurity learning
